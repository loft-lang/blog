# The loft blog

Source of [loft-lang.org/blog](https://loft-lang.org/blog/): notes on building
[loft](https://github.com/loft-lang/loft) and the games and libraries built with it.

GitHub Pages builds the site with Jekyll from `main`. A post is a Markdown file in `_posts/`
named `YYYY-MM-DD-title.md`, starting with front matter:

```yaml
---
layout: post
title: "The post's title"
---
```
